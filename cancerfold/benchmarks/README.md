# Benchmarks

Validation datasets and scripts comparing **CancerFold** predictions against published experimental measurements ($\Delta\Delta G_{\text{exp}}$, mutant PDB/NMR conformational ensembles, and cellular $\text{IC}_{50}$ shifts):

- Cavity / Cryptic Pocket: *TP53* Y220C
- Gatekeeper Steric Resistance: *EGFR* T790M
- Allosteric Switch: *BRAF* V600E
- Neutral / Benign Controls
